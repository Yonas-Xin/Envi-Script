# ENVI 高光谱批量预处理工具

面向资源一号与高分五号系列 AHSI L1 高光谱数据的 ENVI/IDL 工具，将繁琐的多步手动预处理整合为可配置、可批量运行的流程。

在 ENVI 中逐景处理高光谱数据，往往需要反复读取定标与光谱参数、剔除坏波段、合并 VNIR/SWIR、填写 FLAASH 参数并执行正射。本项目通过图形界面和 JSON 配置组织这些步骤，自动读取每景元数据、记录实际参数，并支持断点续跑，减少重复操作与参数遗漏。

> **去噪功能暂不可用**：因版权限制，去噪功能暂不上线，仓库不包含相关第三方程序及运行库。界面保留了去噪选项，但请勿勾选或使用；JSON 配置中的 `denoise.enabled` 必须保持为 `0`。启用后会提示错误并停止处理。

## 功能

1. **辐射定标与波段整理**：读取产品定标系数、波长、FWHM 和 RPC，剔除零增益波段、VNIR/SWIR 重叠波段与水汽强吸收波段，合并为 BIL 辐亮度。
2. **大气校正**：支持 FLAASH、QUAC 或跳过；自动读取成像时间、观测几何和传感器高度，并估算处理区域的中心位置与地面平均高程。
3. **RPC 正射校正**：支持自定义 DEM、像元大小、空间重采样方式和输出坐标系。
4. **统一波段**：以目标传感器确定统一的波长与 FWHM；逐景检查波段覆盖情况，需要时进行光谱重采样。
5. **批量处理与续跑**：多景扫描、测试子区、后台处理、实时日志、参数记录和中间结果管理。

核心处理调用 ENVI/IDL 功能，包括 `RadiometricCalibration`、`ENVIMetaspectralRaster`、`flaash_batch`、`QUAC`、`RPCOrthorectification` 和 `ENVI_SPECTRAL_RESAMPLING_DOIT`。

## 支持的数据

| 传感器 | 支持情况 |
|---|---|
| ZY1E（资源一号 02D）、ZY1F（资源一号 02E） | 已有实际数据处理记录 |
| GF5、GF5A、GF5B | 已实现读取与参数配置，尚未用实际 GF 数据验证 |

每景应保留原始产品目录结构及文件名，包含：

```text
<景目录>/
├── <景名>.xml
├── <景名>_VN.tif / .tiff / .geotiff
├── <景名>_SW.tif / .tiff / .geotiff
├── <景名>_VN.rpb / <景名>_SW.rpb
├── *VNIR_RadCal.raw / *SWIR_RadCal.raw
└── *VNIR_Spectralresponse.raw / *SWIR_Spectralresponse.raw
```

GF-5（01）产品缺少定标文件时，读取器会尝试使用本机 ENVI `ChinaSatellitesSupport` 扩展提供的 GF5 定标文件。

## 运行环境

- 64 位中文 Windows，系统“非 Unicode 程序的语言”设置为简体中文。
- 已安装并授权的 ENVI 5.6 / IDL 8.8；使用 FLAASH 时需具备相应模块许可。其他版本尚未验证。
- 主程序无需 Python。可选的栅格对比工具需要 Python、GDAL 和 NumPy。

`.pro` 源码采用 **GBK** 编码，以适配中文 Windows 下的 IDL 字符串与路径处理。项目附带 VS Code 编码设置；编辑时请保留 GBK。Markdown 文档为 UTF-8。程序能够读取 UTF-8 配置文件，并将其转换为本机 ANSI 编码。

## 快速开始

1. 克隆仓库或下载 ZIP 并解压到 Windows 上可写的目录。
2. 双击根目录的 `HSP_GUI.bat`。启动器自动查找 ENVI；找不到时，按提示选择 ENVI 安装目录。
3. 首次启动时，启动器使用本机 IDL 编译 `hsp_gui_app.sav`，随后打开界面。
4. 选择数据根目录并点击“扫描”，选择待处理景；不选择时处理全部扫描结果。
5. 设置成果目录，检查波段、大气校正、正射及统一波段参数，点击“开始处理”。

建议先在“5 运行选项”中开启测试模式，用一个小子区检查参数；测试结果目录以 `_test` 结尾。全幅处理需要较多磁盘空间，将“中间结果目录”设在本机 SSD 上可以减少共享盘读写开销。

也可以在 IDL Workbench 中打开 `hsp_gui.pro`，编译后运行。

### 参数与默认值

| 参数页 | 主要设置 |
|---|---|
| 去噪与波段 | 水汽吸收区间、额外坏波段、输出波长范围；去噪请保持关闭 |
| 大气校正 | FLAASH / QUAC / None、大气模式、气溶胶、水汽反演、能见度、光谱平滑 |
| 正射 | 是否执行、DEM、像元大小、重采样方式、EPSG |
| 统一波段 | 是否开启、目标传感器 |
| 运行选项 | 断点续跑、保留中间结果、测试子区 |

默认剔除与 1350–1415 nm、1820–1920 nm 水汽区间有重叠的波段，输出中心波长范围为 400–2500 nm。湿润地区可能需要加宽吸收区间，应结合实际数据检查。

默认启用 FLAASH、30 m 最近邻 RPC 正射和以 ZY1E 为目标的统一波段。DEM 留空时使用 ENVI 自带 GMTED2010；EPSG 为 0 时自动选择 UTM 带。每景自动选择 UTM 带不会保证跨带成果处于同一坐标系，需要统一坐标系时应显式指定 EPSG。

完整默认值见 `configs/default.json`，实际默认参数定义在 `core/hsp_config.pro`。界面会将最近使用的配置保存到 `configs/last_gui.json`；此文件属于本机运行状态，不纳入版本管理。

### 无界面批处理

在 IDL Workbench 中修改并运行 `hsp_batch.pro`，所有常用设置都集中在顶部配置区。也可以创建 JSON 配置：

```json
{
  "input_root": "D:\\AHSI\\input",
  "output_root": "D:\\AHSI\\output",
  "work_dir": "D:\\AHSI\\work",
  "test_subset": {
    "enabled": 1,
    "sub_rect": [800, 800, 1099, 1099]
  },
  "flaash": {
    "atmosphere": "Auto"
  }
}
```

只需提供与默认值不同的字段，然后在 Windows 命令行运行：

```bat
tools\run_batch.bat "D:\AHSI\config.json"
```

或将配置文件路径写入 `hsp_batch.pro` 的 `config_file`。界面的“保存配置”按钮也能生成批处理配置。

## 统一波段

不同传感器以及不同定标版本的中心波长和有效波段可能不同。工具根据 `srf/` 中的 ZY1E / ZY1F 光谱与定标表建立统一波段表，写入成果根目录的 `band_table.csv`。

- 波段逐一匹配时直接选取对应波段。
- 波段不匹配时，在大气校正与正射后按中心波长、FWHM 进行光谱重采样，另存裁到输出波长范围的原始成果。
- 目标波段超出源数据范围、或附近缺少足够有效波段时，预检报错并跳过该景，避免生成全 0 波段。

也可通过 `resample.reference_dir` 指定其他传感器某一景的目录作为参考。统一波段表取决于参考文件、坏波段规则和输出范围，分批处理时需保持这些设置一致。

## 输出与断点续跑

```text
<成果根目录>/
├── hsp_run_<时间>.log
├── band_table.csv
└── <景名>/
    ├── 02_radiance/       合并辐亮度，Float / BIL
    ├── 03_reflectance/    FLAASH / QUAC 反射率（默认 ×10000）
    ├── 04_ortho/          RPC 正射成果
    ├── 05_resample/       光谱重采样成果及裁剪后的原始成果
    ├── params.json        本景参数与成果路径
    └── process.log        本景日志
```

可选步骤关闭时不会生成相应目录。默认处理成功后删除中间结果，仅保留最终成果和日志；处理失败时保留中间结果，便于续跑。

启用“复用已存在的步骤结果”后，程序检查文件完整性、波长及 `<结果名>_step.sig` 参数记录；设置不匹配或未完成写出的结果会重新计算，并使后续步骤重新执行。处理在独立后台进程中运行，界面可查看日志或强制停止；关闭界面时会同时结束后台处理。

## 项目结构

| 文件或目录 | 用途 |
|---|---|
| `HSP_GUI.bat` | Windows 图形界面启动器 |
| `hsp_gui.pro` / `hsp_gui_app.pro` | 界面与后台处理入口 |
| `hsp_batch.pro` | 配置集中在顶部的批处理入口 |
| `hsp_init.pro` | 模块加载与编译 |
| `core/` | 配置、传感器、数据读取、定标、波段整理、大气校正、正射、重采样、流程与日志 |
| `configs/default.json` | 默认配置参考 |
| `srf/` | ZY1E / ZY1F 参考波段与定标表 |
| `tools/` | ENVI 查找、启动器编译、taskengine 入口、进程看护与栅格对比 |
| `docs/预处理方案.md` | 算法、参数与实现说明 |
| `docs/对比验证.md` | 已记录的 ENVI 界面逐步对照结果 |

去噪第三方程序及运行库、编译得到的 `.sav`、DEM、遥感影像、处理成果、日志和本机路径缓存均不随仓库分发。

## 验证记录

项目已有 ENVI 5.6 / IDL 8.8 下的 ZY1E 300×300 子区对照记录：定标差异处于浮点舍入范围，FLAASH 有 99.74% 的数值差异不超过 1（反射率 ×10000），RPC 正射网格与有效像元位置一致。具体数据、参数与适用范围见 [对比验证](docs/对比验证.md)，算法细节见 [预处理方案](docs/预处理方案.md)。

这些记录来自所列数据与参数，其他传感器、区域及 ENVI 版本需单独验证。
