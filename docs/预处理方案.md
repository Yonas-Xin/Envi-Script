# 高光谱数据批量预处理工具方案（ENVI/IDL）

## 1. 目标与范围

面向资源一号 02D/02E（产品代号 ZY1E/ZY1F）与高分五号系列（GF5/GF5A/GF5B）AHSI L1 级高光谱数据，提供一个带简单图形界面的 IDL 工具，对多景数据按固定流程批量处理：

1. 去噪入口保留，但因版权限制暂不上线，请勿启用
2. 读取数据并挂载元数据（波长、FWHM、定标系数、RPC、成像参数）
3. 辐射定标
4. 坏波段剔除与 VNIR/SWIR 合并
5. 大气校正（FLAASH，可选 QUAC）
6. RPC 正射校正
7. 输出成果与处理日志

运行环境：64 位中文 Windows + ENVI 5.6 / IDL 8.8；使用 FLAASH 时需要对应许可。

## 2. 数据结构（以示例景为例）

示例景：`ZY1E_AHSI_E96.36_N35.73_20201031_005956_L1A0000196617`

| 文件 | 内容 |
|---|---|
| `*_VN.tiff` | VNIR 影像，76 波段，1999×2051，UInt16，DN 值，BSQ |
| `*_SW.tiff` | SWIR 影像，90 波段，1999×2051，UInt16，DN 值，BSQ |
| `*_VN.rpb` / `*_SW.rpb` | RPC 参数（两个文件内容一致），ENVI 打开 tiff 时自动读取 |
| `ZY1E_AHSI_VNIR_RadCal.raw` / `..._SWIR_RadCal.raw` | 每波段定标系数，两列：gain、offset |
| `ZY1E_AHSI_VNIR_Spectralresponse.raw` / `..._SWIR_...raw` | 每波段中心波长（nm）与 FWHM（nm） |
| `*.xml` | 景元数据：成像时间、中心经纬度、四角坐标、太阳/卫星天顶角与方位角、GSD 等 |
| `*_Check.xml`、`*.shp`、`*_Cloud.shp`、`*.jpg` | 质检信息、景框、云区、快视图 |

示例景的关键参数（取自 `*.xml`）：成像时间 2020-10-31 04:39:23 UTC，中心 35.7309°N / 96.3544°E，太阳天顶角 50.79°，太阳方位角 167.88°，卫星天顶角 0.36°，卫星方位角 173.64°，GSD 33.2 m，RPC 高程偏移 4394.5 m。

波段特征：

- VNIR：395.9–1040.2 nm，FWHM 8.76 nm；第 71 波段为 996.9 nm，第 72–76 波段（1005.8–1040.2 nm）与 SWIR 起始段重叠。
- SWIR：1005.6–2501.1 nm，FWHM 16.26 nm；定标系数为 0 的波段为第 22–25 波段（1357.9–1408.5 nm）与第 50–55 波段（1828.8–1913.0 nm），对应水汽强吸收区。

## 3. ENVI 预处理流程与已验证的实现方式

以下各步均已在虚拟机中用示例景的 300×300 像元子区实际运行通过。

### 3.1 读取与元数据挂载

不依赖第三方扩展，直接按文件结构读取：

- 用 `e.OpenRaster(tiff, METADATA_OVERRIDE=md)` 打开 VN/SW tiff，`md` 中写入 `wavelength`、`fwhm`、`wavelength units`、`data gain values`、`data offset values`、`data ignore value = 0`。
- RPC 由同名 `.rpb` 自动读入，空间参考类型为 `ENVIRPCRasterSpatialRef`。
- 成像参数从 `*.xml` 解析，供 FLAASH 使用。
- 影像扩展名支持 `.tif`、`.tiff`、`.geotiff`（ZY1F/GF5A、ZY1E、GF5 分别采用）；`RadCal.raw` 只有一列时 offset 取 0，`Spectralresponse.raw` 只有一列时按相邻波长间隔估计 FWHM；GF-5（01）产品缺少 `RadCal.raw` 时使用 ENVI 国产卫星扩展自带的 `GF5_AHSI_*_RadCal.raw`。

### 3.1.1 各卫星参数

需要按卫星区分的参数由 `core/hsp_sensor.pro` 中的参数表按 XML 的 `SatelliteID` 自动选取：

| 卫星代号 | 卫星 | 轨道高度 | 波段（VNIR + SWIR） | 依据 |
|---|---|---|---|---|
| ZY1E | 资源一号 02D | 778 km | 76 + 90 = 166 | 自然资源部发布信息；Gunter's Space Page |
| ZY1F | 资源一号 02E | 778 km | 76 + 90 = 166 | 自然资源部发布信息；Gunter's Space Page |
| GF5 | 高分五号（01） | 705 km | 150 + 180 = 330 | WMO OSCAR；Gunter's Space Page |
| GF5A | 高分五号 01A | 705 km | 150 + 180 = 330 | 发射报道（进入 705 km 预定轨道）；ENVI 国产卫星扩展处理 GF5A 时写入的传感器高度为 705 |
| GF5B | 高分五号 02 | 705 km | 150 + 180 = 330 | WMO OSCAR（gf_5_02） |

ZY1E 的 778 km 与 ENVI `OpenChinaRaster` 读取该数据时给出的传感器高度一致。GSD 优先取 XML 中的 `ImageGSD`，缺失时取 30 m。GF 系列的读取按产品文件结构编写（与 ZY1 系列相同的 XML、RadCal、Spectralresponse 组织方式），尚未用 GF 实际数据验证；XML 标签名与 ZY1 不同时，读取器会尝试常见的替代标签，仍找不到成像时间或经纬度时报错并给出缺失的标签。

ENVI 5.6 自带的 `OpenChinaRaster` 任务（ChinaSatellitesSupport 扩展）也能读取该数据：输入 `*.xml`、传感器类型选 `ZY102d`，得到 166 波段虚拟栅格并自动带上定标系数、波长、太阳角与传感器高度（778 km）。该任务会在原始数据目录写入一个 `*_VNSW.meta` 文件，且要求文件名与原始产品完全一致，去噪后的数据难以直接沿用，因此工具采用上面的自读方式，`OpenChinaRaster` 仅作为备选读取器保留。

### 3.2 辐射定标

使用 `RadiometricCalibration` 任务，VN、SW 分别处理：

$$L = DN \times gain + offset \quad (\mathrm{W \cdot m^{-2} \cdot sr^{-1} \cdot \mu m^{-1}})$$

FLAASH 要求输入单位为 $\mathrm{\mu W \cdot cm^{-2} \cdot sr^{-1} \cdot nm^{-1}}$，两者换算系数为 0.1：

$$L_{\mathrm{FLAASH}} = 0.1 \times L$$

任务参数：`CALIBRATION_TYPE='Radiance'`，`SCALE_FACTOR=0.1`，`OUTPUT_DATA_TYPE='Float'`，`OUTPUT_RASTER_URI='!'`。输出 URI 为 `!` 时 ENVI 返回虚拟栅格，定标在读取时逐块计算，不写盘；定标后 RPC 保留。

### 3.3 坏波段剔除与 VNIR/SWIR 合并

- 剔除规则（可在配置中修改）：
  - 定标系数 gain = 0 的波段（自动识别，ZY1E 示例景共 10 个）；
  - VNIR 中波长不小于 SWIR 首波段波长的重叠波段（ZY1E 的 SWIR 首波段为 1005.6 nm，剔除第 72–76 波段；GF-5 同理自动确定）；
  - 与水汽强吸收区间 1350–1415 nm、1820–1920 nm 有重叠的波段：波段响应范围（中心 ± FWHM/2）与区间重叠即剔除。ZY1E 定标文件中这两段的 gain 为 0，ZY1F 的定标文件只给 gain 且这些波段 gain 不为 0，只能按波长剔除。按中心波长判断时，ZY1F 的 1414.0 nm、1919.4 nm 离区间边界不到 1 nm，各景光谱定标约 1 nm 的漂移就会改变剔除结果，而这些强吸收波段一旦进入 FLAASH 就会出问题（见 3.4 节末）。按响应范围判断时，保留下来的波段整个响应范围都在吸收区间之外；紧贴边界的波段（如 ZY1E 的 1341.2 nm 响应上限 1349.3 nm、1812.0 nm 响应上限 1820.1 nm）仍可能因定标漂移时留时剔，但它们不是强吸收波段，某景剔除后由统一波段重采样补齐（3.6 节），不影响成果的一致性。该规则比按中心波长多剔除 ZY1E 的 1812.0 nm、ZY1F 的 1346.6 nm 与 1818.3 nm；
  - 用户自定义的额外坏波段列表（如 SWIR 末端低信噪比波段）；
  - 输出波长范围之外的波段（默认只保留中心波长在 400–2500 nm 内的波段，可取消或修改；对所有景生效，使不同传感器的成果波段范围一致）。
- 用 `ENVISubsetRaster(BANDS=...)` 选波段，再用虚拟栅格 `ENVIMetaspectralRaster` 合并。VN、SW 的 RPC 完全一致、行列数相同，可直接合并，合并结果仍为 RPC 空间参考。
- 示例景合并后为 149 波段（VNIR 70 + SWIR 79；不限定波长范围时为 151 波段）。
- 用 `raster.Export, uri, 'ENVI', INTERLEAVE='bil'` 导出为 BIL 格式，满足 FLAASH 输入要求。定标、选波段与合并都是虚拟栅格，整个过程只写出这一个文件。`BuildBandStack` 任务会先在 ENVI 会话临时目录写一份与结果等大的文件，会话异常结束时不会被清理，因此不使用。

### 3.4 大气校正

ENVI 5.6 的 Task 列表中没有 FLAASH 任务，FLAASH 通过经典批处理对象 `flaash_batch` 调用（已确认可用且许可证有效）：

```idl
fo = obj_new('flaash_batch', /anc_delete)
fo->SetProperty, hyper=1, radiance_file=rad_bil, reflect_file=refl, $
  modtran_directory=work_dir, lambda=wl_um, fwhm=fwhm_um, $
  input_scale=replicate(1.0, nb), output_scale=10000.0, ...
fo->processImage
```

参数来源：

| 参数 | 取值方式 |
|---|---|
| `latitude` / `longitude` | 处理区域有效像元的中心（见下）；统计失败时取 xml 中心经纬度 |
| `year` / `month` / `day` / `gmt` | xml 成像起止时间的中点（UTC，小时制） |
| `sensor_altitude` | 按卫星参数表（3.1.1） |
| `ground_elevation` | 处理区域有效像元对应的 DEM 高程均值（km，见下） |
| `pixel_size` | xml 中的 GSD |
| `view_zenith_angle` | 180 − 卫星天顶角（FLAASH 约定 180° 为天底观测） |
| `view_azimuth` | xml 卫星方位角 |
| `atmosphere_model` | 默认按纬度与月份查 FLAASH 推荐表自动选择，可手动指定 |
| `aerosol_model` | 默认乡村型（Rural） |
| `aerosol_retrieval` | 默认 2-Band (K-T) 反演；0 为不反演，直接使用初始能见度 |
| `visvalue` | 初始能见度，默认 40 km |
| `water_retrieval` / `water_band_choice` | 开启水汽反演，使用 1135 nm 吸收带 |
| `polishing_res` | 光谱平滑（polishing）宽度，默认 9 个波段，0 表示关闭 |
| `use_tiling` / `tile_size` | 默认不分块，整景一次处理；配置项 `tile_size_mb` 大于 0 时按该大小（MB）分块。分块时 FLAASH 对每块单独反演能见度与水汽、单独计算光谱平滑，拼接后块间留下 0.5–1% 的反射率台阶（ZY1E 全景 2051×1999×148 按 200 MB 分为 4×4 块时实测），MNF 等按噪声归一化的变换会把这些台阶放大成主要成分，因此只在内存不足时才分块 |
| `output_scale` | 10000（输出为 Int16 反射率 × 10000） |

地面高程与中心经纬度的统计方法：取辐亮度中最接近 860 nm 的波段，用 ENVI 的 RPC 正射（最近邻、约 300 像元宽的粗分辨率）得到处理区域在地面上的实际范围；只取其中有效像元（排除影像无效区与正射背景）对应的 DEM 高程求均值，DEM 自身的无效值也排除。四角经纬度的外接矩形会包含景框外的区域，影像中也可能有无效区，按有效像元统计可以避免它们影响结果；测试子区模式下统计的就是子区本身。该方法失败时依次退回四角外接矩形内的 DEM 均值、RPC 高程偏移。示例景全幅按外接矩形统计为 4.439 km，300×300 子区按有效像元统计为 4.200 km。

`flaash_batch` 的模式参数使用 MODTRAN 原生编码，而不是 FLAASH 界面下拉框的顺序。编码对照（已通过对照实验确认）：

| 参数 | 编码 |
|---|---|
| `atmosphere_model` | 1 Tropical，2 Mid-Latitude Summer，3 Mid-Latitude Winter，4 Sub-Arctic Summer，5 Sub-Arctic Winter，6 U.S. Standard |
| `aerosol_model` | 0 No Aerosol，1 Rural，4 Maritime，5 Urban，6 Tropospheric |

确认方法：关闭水汽反演后，940 nm 与 1135 nm 水汽吸收带的反射率按编码 1 > 2 > 4 > 6 > 3 > 5 递减，与各模式大气水汽柱含量（Tropical 4.11、MLS 2.92、SAS 2.08、US 1.42、MLW 0.85、SAW 0.42 g/cm²）的排序一致；气溶胶编码 2、3 与 1 结果完全相同，0、4、5、6 各不相同。工具界面只显示模式名称，由代码换算为编码，避免误填。

大气模式自动选择采用 FLAASH 用户指南的纬度–月份推荐表（行：纬度取最近的 10° 档；列：1–2 月取 Jan、3–4 月取 Mar、5–6 月取 May、7–8 月取 Jul、9–10 月取 Sep、11–12 月取 Nov）。示例景（35.7°N，10 月）按表得到 Mid-Latitude Summer；对于青藏高原等高海拔、低水汽地区，开启水汽反演后大气模式对结果影响较小，也可手动改为 Sub-Arctic Summer 或 Mid-Latitude Winter。

实测结果（300×300×151 子区）：

- 开启水汽反演 + K-T 气溶胶反演：耗时约 90–100 秒，反射率中位数在 0.07–0.33 之间，负值像元比例约 7×10⁻⁶；
- 关闭两项反演：耗时约 30–45 秒；
- 两种气溶胶设置（K-T 反演 / 固定能见度 40 km）结果平均相差约 26（反射率 × 10000）；
- 耗时主要为 MODTRAN 计算，与影像大小关系不大。

FLAASH 输出会保留 RPC 信息，可直接进入正射。

`QUAC` 任务可作为快速替代（无需成像参数），在配置中切换。

强吸收波段对 FLAASH 的影响（ZY1F 300×300 子区实测）：FLAASH 把大气透过率接近 0 的波段（1363–1397 nm、1835–1919 nm 附近）输出为 0，具体是哪些波段随水汽量和地面高程变化；光谱平滑（polishing）按相邻波段计算，单个全 0 波段会使相邻波段的粗糙度从约 2% 升到约 48%，一段连续多个全 0 波段（实测为 1835–1919 nm 的 6 个波段）会使整景所有波段都输出为 0，且 FLAASH 不报错。各组对照：不剔除水汽波段且同时开启水汽反演与光谱平滑时 163 个波段全部为 0；只关闭光谱平滑时 9 个强吸收波段为 0；只关闭水汽反演时 6 个为 0；按 3.3 节剔除水汽波段时没有全 0 波段。ZY1E 定标文件中这些波段的 gain 为 0，总会被剔除；ZY1F 只依赖按波长剔除，因此剔除规则需要稳健（3.3 节）。实测区域干旱、海拔高、水汽少；处理湿润低海拔地区时强吸收带更宽，必要时可加宽水汽吸收区间（如 1340–1460 nm、1790–1960 nm）。

### 3.5 RPC 正射校正

使用 `RPCOrthorectification` 任务：

- `DEM_RASTER`：默认使用 ENVI 自带的 `C:\Program Files\Harris\ENVI56\data\GMTED2010.jp2`，可替换为更高精度的 DEM（如 SRTM/ALOS 30 m）；
- `OUTPUT_PIXEL_SIZE`：默认 30 m；
- `RESAMPLING`：默认 Nearest Neighbor（保持光谱不被混合）；
- `OUTPUT_COORDINATE_SYSTEM`：默认自动选择 UTM 带（示例景为 UTM 47N），可指定。

实测 300×300 子区正射耗时约 4 秒。

### 3.6 统一波段与光谱重采样

同一批处理中有不同传感器的景时，各景波长不同：ZY1E 与 ZY1F 的 AHSI 设计相同，但 ZY1F 的 VNIR 中心波长比 ZY1E 短约 9 nm（约一个波段），SWIR 长 4–8 nm。同一传感器的不同景，定标文件中系数为 0 的波段和光谱定标也可能不同。为使所有成果的波段数与波长严格一致，工具使用统一波段表：

- 统一波段表：取目标传感器的光谱响应与定标文件（项目 `srf/<传感器>/` 中保存了 ZY1E、ZY1F 示例景的文件，也可用 `resample.reference_dir` 指定任意一景的目录），按 3.3 节的规则（额外坏波段除外）剔除坏波段，保留中心波长在输出波长范围内的波段。以 ZY1E 为目标、400–2500 nm 时为 148 个波段（404.5–2484.3 nm），以 ZY1F 为目标时同为 148 个（404.0–2492.2 nm）。波段表与每批处理哪些景无关，处理开始时写入成果目录的 `band_table.csv`，统一成果头文件中的波长与 FWHM 直接取自该表。
- 预检：处理前读取各景的定标与光谱响应文件。定标系数为 0 但不在剔除规则范围内的独立坏波段按景列出警告并汇总景名；统一波段表中的波段若超出某景源数据范围，或附近没有有效源波段（一个 FWHM 内没有，且两侧 1.5 个 FWHM 内不同时有），该景不处理。ZY1E、ZY1F 互为目标时全部满足：以 ZY1E 为目标时每个目标波段离最近的 ZY1F 有效波段最多 11.4 nm，反之最多 7.9 nm。
- 逐景方案：统一波段表中每个波段都能在该景找到中心波长相差不超过 0.01 nm 的有效波段时，第 2 步只取这些波段，最终成果即统一成果；否则保留该景全部有效波段（不按输出波长范围裁剪），完成 FLAASH 与正射后重采样到统一波段表，输出 `05_resample/<成果名>_to_<目标>.dat`，未重采样的原始成果按自身波长裁到输出波长范围，另存为 `05_resample/<成果名>.dat`，正射结果保持不变。
- 方法：ENVI Classic 的 `ENVI_SPECTRAL_RESAMPLING_DOIT`（ENVI 界面 Spectral Resampling 所用的例程），关键字 `OUT_WL`、`OUT_FWHM`、`OUT_DT`，按输入与目标的中心波长和 FWHM 构造高斯光谱响应函数。ENVI 5.6 的 `ResampleSpectrum` 任务只处理单条光谱，不适合整幅影像。该例程对超出源数据波长范围的目标波段整段填 0，这是预检要求目标波段位于源数据范围内、源数据在重采样前不裁剪的原因；范围内的空缺（如单个坏波段）由两侧插值。每个目标波段只由附近的源波段加权得到，直接重采样到范围内的波段与“重采样全部波段后再裁剪”结果相同。
- 位置：在大气校正与正射之后，对最终成果进行。反射率光谱平滑，重采样误差小；辐亮度中的大气吸收谷很窄，在 FLAASH 之前重采样误差较大，且保留原始成果需要把 FLAASH 运行两次。光谱重采样是逐像元的线性加权，正射（最近邻或线性插值）也是线性运算，两者先后顺序不影响结果，放在最后只需正射一次。
- 输出：数据类型与原始成果相同（反射率为 Int16），无效值、反射率比例系数、地图信息沿用原始成果。
- 实测（ZY1E、ZY1F 各 300×300 子区）：以 ZY1E 为目标时 ZY1E 直接取波段，ZY1F 由 151 个波段重采样为 148 个（约 4 s），两份统一成果头文件中的波长、FWHM、波段数、数据类型、无效值逐项一致，均无全 0 波段；与用高斯光谱响应独立计算的结果相比，逐波段相对差中位数 0.06%，最大 1.6%（位于 VNIR 与 SWIR 交界处）。把 ZY1F 定标文件中 635.8 nm 与 1616.2 nm 的系数人为改为 0 后，预检报告独立坏波段，统一成果中这两个波段由两侧插值得到，数值介于相邻波段之间。

### 3.7 处理顺序

```
原始 L1A (DN)
  └─ 1 去噪（暂不上线，保持关闭）
      └─ 2 读取、挂载元数据 / RPC、辐射定标、坏波段剔除、VNIR/SWIR 合并 → BIL
          └─ 3 FLAASH / QUAC
              └─ 4 RPC 正射
                  └─ 5 统一波段：与统一波段表不一致的景做光谱重采样（原始成果保留）
                      └─ 6 输出成果 + 日志
```

大气校正放在正射之前：FLAASH 在原始成像几何上处理，避免正射重采样后的像元混合和大面积无效边框带来的额外计算，并且 FLAASH 输出保留 RPC，可以直接正射。

## 4. 去噪

因版权限制，去噪功能暂不上线。仓库不包含 `proc_BatchDenoising.exe`、`denoise/` 运行库或第三方算法实现。请勿使用去噪功能：界面中保持“去噪”未勾选，批处理配置中保持 `denoise.enabled = 0`。

`core/hsp_denoise.pro` 仅保留外部程序调用接口；公开版在配置校验和调用接口中阻止去噪执行，并提示关闭该选项。

### 5.1 输出目录结构

```
<成果根目录>/<景名>/
├── 02_radiance/     定标、坏波段剔除与合并后的 BIL 辐亮度
├── 03_reflectance/  FLAASH / QUAC 反射率
├── 04_ortho/        正射后反射率（不需要重采样的景的最终成果）
├── 05_resample/     需要重采样的景的最终成果：重采样成果（_to_<目标>）与裁到输出波长范围的原始成果
├── params.json      本景实际使用的全部参数
└── process.log      处理日志
```

设置中间结果目录时，01–05 写入该目录，最终成果复制到成果目录。每一步成功后在结果旁写入参数记录 `<结果名>_step.sig`（本步与前面各步的参数及波段波长）。`skip_existing` 开启时，结果存在、参数记录与本次一致且波段与当前方案相符的步骤直接跳过，可从中断处继续；中断时写了一半的结果没有参数记录，参数改动后的结果记录不符，都会重新计算，其后各步随之重新计算。默认在处理成功后删除中间结果，仅保留最终成果；处理失败时保留，便于续跑。FLAASH 以 ENVI Classic 方式打开反射率与水汽、云掩膜文件且不释放，结束后需用 `envi_file_mng, /remove` 关闭这些文件，否则无法删除。测试子区模式下景目录名加 `_test`，与全幅结果分开。

### 5.2 图形界面

用 IDL 原生控件（`WIDGET_BASE` 等）实现，不需要安装 Python 等额外环境。界面只显示需要人为选择的参数，能按数据自动确定的参数（定标比例系数、传感器高度、地面高程、中心经纬度、成像时间、观测角度、重叠波段、水汽吸收带等）不显示：

- 数据与目录：数据根目录（自动扫描其中所有 AHSI L1 景）、成果目录、中间结果目录，景列表可多选；
- 去噪与波段：去噪选项保持关闭；可设置剔除波长区间、额外坏波段、输出波长范围；
- 大气校正：方法（FLAASH / QUAC / 不做）、大气模式、气溶胶模型与反演方式、初始能见度、水汽反演、光谱平滑宽度；
- 正射：是否正射、DEM、输出像元大小、空间重采样方式、输出坐标系；
- 光谱重采样：是否重采样、目标传感器；
- 运行选项：断点续跑、保留中间结果、测试子区；
- 按钮：载入配置、保存配置、开始处理、强制停止（立即结束后台进程及其子进程）、清空日志；
- 日志窗口：实时显示当前景、当前步骤、耗时与错误。

未显示的参数保留在配置中，可通过配置文件修改；界面读取参数时在当前载入的配置上覆盖界面中的值，不会把这些参数重置为默认值。

### 5.3 运行方式

1. **图形界面**：双击 `HSP_GUI.bat`。启动器与 ENVI 自身的启动方式相同，用 `idlrt.exe -novm` 以运行模式打开 `hsp_gui_app.sav`，入口先以无界面方式启动 ENVI，再打开工具界面。`hsp_gui_app.sav` 只包含本项目例程和界面所需的 IDL 库例程（xmanager 等）：JSON、LIST、HASH 等库例程由 ENVI 启动时加载，重复编入会与之冲突；ENVI 的例程中含有名为 `MAIN` 的过程，编入后运行模式会优先执行它而启动 ENVI Classic。源码比 `hsp_gui_app.sav` 新时，启动器先调用 `tools\build_launcher.bat`（纯 IDL 引擎，不加载 ENVI）重新生成。也可在 IDL Workbench 中打开 `hsp_gui.pro` 运行。
2. **无界面批处理**：修改 `hsp_batch.pro` 顶部配置区后在 IDL 中运行；或执行 `tools\run_batch.bat <配置文件.json>`，通过 ENVI taskengine 在后台运行。

ENVI taskengine 需加 `--compile` 参数并通过 `IDL_PATH` 指向项目根目录、`core` 与 `tools`，才能编译并运行项目中的 `.pro` 源码。`IDL_PATH` 只需包含项目根目录、`core`、`tools` 和 IDL 默认路径。

### 5.4 字符编码

中文 Windows 上，IDL 控件、IDL Workbench 编辑器与 `FILE_SEARCH` 返回的路径均按系统 ANSI（GBK）编码处理；UTF-8 源码中的中文在界面上显示为乱码，与 GBK 路径拼接后写入 `.bat` 也会出错。因此 `.pro` 源码统一保存为 GBK，生成的 `.bat`、`.ps1`、日志和配置文件均为 GBK；读取 UTF-8 编码的配置文件时先转换为 GBK。

## 6. 性能

ZY1E 示例景全幅（1999×2051 像元）实测，数据在共享目录，结果写入 Windows 本地盘：

| 步骤 | 耗时 | 结果大小 |
|---|---|---|
| 辐射定标、坏波段剔除与合并（151 波段，Float，BIL） | 73 s | 2.5 GB |
| FLAASH（水汽反演 + K-T 气溶胶反演） | 265 s | 1.2 GB（Int16） |
| RPC 正射（30 m，输出 2510×2729） | 88 s | 2.1 GB |
| 合计 | 约 7 min | 约 5.8 GB |

默认不保留中间结果，成功后只留最终成果。关闭水汽与气溶胶反演时 FLAASH 的 MODTRAN 部分可缩短约 1 分钟；中间结果放在虚拟机本地磁盘（配置 `work_dir`，如 `C:\hsp_work`）读写更快。

## 7. 与 ENVI 界面的对比

用 ZY1E 示例景 300×300 子区，在 ENVI 界面中以相同参数依次完成辐射定标、FLAASH 和 RPC 正射，与脚本结果逐波段比对：定标差异仅为浮点舍入；FLAASH 参数逐项一致，99.74% 的数值差异在 Int16 取整误差以内，逐波段相对差最大 0.18%；正射输出网格、有效范围与取样位置完全一致。详见 [对比验证.md](对比验证.md)。
