# 脚本与 ENVI 界面处理结果对比

## 1. 测试数据与方法

- 数据：ZY1E（资源一号 02D）`ZY1E_AHSI_E96.36_N35.73_20201031_005956_L1A0000196617`
- 区域：像元子区 [800, 800, 1099, 1099]（从 0 起算，300×300 像元）
- 日期：2026-10-25；ENVI 5.6 / IDL 8.8
- 脚本端：本工具默认参数（不去噪，FLAASH 开启水汽反演与 K-T 气溶胶反演，RPC 正射 30 m 最近邻）
- 界面端：在 ENVI 5.6 界面中逐步操作，参数按脚本 `params.json` 中记录的实际值填写
- 比对：`tools/compare_rasters.py`，按波长匹配波段、按地图坐标或像元位置对齐，逐波段统计平均绝对差（MAE）、相对 MAE（MAE 与界面结果均值之比）、最大绝对差和相关系数

| 步骤 | 脚本 | ENVI 界面 |
|---|---|---|
| 读取 | 自行解析 XML、RadCal、Spectralresponse，`OpenRaster(METADATA_OVERRIDE)` | Toolbox → Extensions → China Satellites → ZiYuan → ZY1-02D (ZY1E)，打开 XML |
| 辐射定标 | `RadiometricCalibration`，比例系数 0.1 | Radiometric Calibration，比例系数 1.0（界面默认），全幅 |
| 大气校正 | `flaash_batch` | FLAASH Atmospheric Correction，输入为脚本生成的同一份合并辐亮度（`02_radiance`） |
| 正射 | `RPCOrthorectification` | RPC Orthorectification Workflow，输入为界面 FLAASH 的结果 |

## 2. 辐射定标

界面定标结果为 W/(m²·sr·μm)，脚本结果为 μW/(cm²·sr·nm)（比例系数 0.1），比对前把脚本结果乘以 10。

| 部分 | 波段数 | 最大绝对差 (W/(m²·sr·μm)) | 相对 MAE | 最小相关系数 |
|---|---|---|---|---|
| VNIR | 76 | 1.1×10⁻⁵ | < 10⁻⁶ % | 1.000000 |
| SWIR | 90 | 6.7×10⁻⁶ | < 10⁻⁶ % | 1.000000 |

SWIR 中定标系数为 0 的 10 个波段两边均为 0，完全一致；其余波段的差异只是 Float 运算中乘以 0.1 再乘以 10 的舍入误差。两边的波长、定标系数和辐亮度一致，说明脚本自行读取的元数据与 ENVI 国产卫星读取器的结果相同。

### 3.2 结果比对

| 指标 | 数值 |
|---|---|
| 数值完全相同的比例（像元 × 波段） | 87.40% |
| 差值不超过 1（反射率 ×10000）的比例 | 99.74% |
| 差值大于 10 的比例 | 0.0097% |
| 某一波段差值大于 10 的像元 | 64 / 90000 |
| 逐波段相对 MAE | 中位数 0.003%，最大 0.18%（第 1 波段，395.9 nm） |
| 最大绝对差 | 109（第 117 波段 1929.9 nm 的单个像元，反射率 0.2832 对 0.2723） |
| 逐波段最小相关系数 | 0.99999 |
| 三个波段的区域平均反射率（×10000，脚本 / 界面） | 473.2 nm：1060.48 / 1060.51；902.7 nm：2706.62 / 2706.49；1980.6 nm：2240.25 / 2240.21 |

差值不超过 1 的部分是 Int16 取整造成的。少量较大差值来自界面把经纬度、地面高程和成像时间截断到 4 位小数，这些微小差异会让个别像元在水汽查找表中落到相邻的格点。两边结果在实际应用中可视为相同。

## 4. RPC 正射

界面工作流的设置：DEM 为 GMTED2010（自动勾选大地水准面校正，该区域为 −44.77 m），输出坐标系 UTM 47N，像元 30 m，最近邻重采样，网格间距 10。

| 指标 | 结果 |
|---|---|
| 输出尺寸 | 两边均为 374 × 400 |
| 左上角坐标 | 两边均为 (254317.828, 3965601.768) |
| 有效像元 | 两边均为 98875 个，位置完全重合 |
| 像元值差异 | 差异比例 12.60%，差值大于 2 的比例 0.02%，与 FLAASH 阶段相同 |

正射后的差异比例与 FLAASH 阶段完全相同，说明两边每个输出像元取自同一个源像元，几何处理没有引入任何差异；脚本调用的 `RPCOrthorectification` 任务默认也做了相同的大地水准面校正。

## 5. 界面默认值与脚本的不同

手动在界面中处理时，以下默认值与脚本不同，需要留意：

| 项目 | ENVI 界面默认 | 脚本 |
|---|---|---|
| FLAASH 中心经纬度 | 按 RPC 取影像中心（35.75134722, 96.34467222） | 处理区域有效像元的中心（35.75103168, 96.34497650），两者相距约 40 m |
| FLAASH 像元大小 | 按 RPC 估算（29.4 m） | XML 中的 GSD（33.2 m） |
| FLAASH 地面高程、传感器高度、成像时间 | 需手动填写（默认 0） | 自动确定 |
| FLAASH 水汽反演 | 打开 UNKNOWN-HSI 数据时被重置为“否” | 默认开启 |
| 正射像元大小 / 重采样 | 29 m / 双线性 | 30 m / 最近邻 |
| 辐射定标比例系数 | 1.0 | 0.1（FLAASH 所需单位） |

## 6. 结论

- 辐射定标：与 ENVI 国产卫星读取器加界面定标的结果一致，差异仅为浮点舍入。
- FLAASH：参数逐项一致；结果 99.74% 的数值差异在取整误差以内，逐波段相对差最大 0.18%。
- RPC 正射：输出网格、有效范围和取样位置完全一致。

脚本的处理与在 ENVI 界面中用相同参数手动处理等价。
